🎬 Movie Recommendation System
This is a content-based movie recommendation system built using the TMDB 5000 Movie Dataset. The system suggests similar movies based on genres, cast, crew, and keywords. It uses Natural Language Processing (NLP) techniques and cosine similarity for generating recommendations. The full-stack web app is built using ReactJS (frontend) and Flask (backend).

🚀 Features
Content-based movie recommendation using NLP

TMDB 5000 dataset used as base

Vectorization using CountVectorizer

Cosine similarity for recommendation engine

Frontend built using ReactJS

Backend built using Flask API

Integration with pre-trained model for fast response

🧠 Tech Stack
Frontend: ReactJS, Axios, Bootstrap

Backend: Flask, Pandas, Scikit-learn

ML/NLP: CountVectorizer, Cosine Similarity, Stemming, ast.literal_eval

Deployment Tools: Flask-RESTful, pickle
